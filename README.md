## About This Repository

Each program is organized in its own topic folder within a chapter. The original C++ filenames and source contents have been preserved. The repository progresses from basic input/output and functions through classes, constructors, inheritance, polymorphism, operator overloading and exception handling.

## Learning Areas

- **C++ fundamentals:** data types, input/output, arrays, strings, functions, and parameter passing.
- **Classes and objects:** member functions, scope resolution, `this` pointer, object arguments, and encapsulation.
- **Object lifecycle:** constructors, copy constructors, destructors, and static members.
- **Friend functions:** accessing private data and working across classes.
- **Inheritance:** single, multilevel, multiple, initializer lists, and virtual inheritance.
- **Polymorphism:** virtual functions, pure virtual functions, and operator overloading.
- **Exception handling:** `try`, `catch`, nested blocks, catch-all handlers, and validation examples.
